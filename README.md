# 🍽️ Cloud Kitchen Web App

A modern and responsive web application for exploring and ordering food online from a cloud kitchen.

## ✨ Features

- 🏠 Modern and responsive user interface
- 🍔 Browse food items and menu
- 🛒 Add items to cart
- 📱 Mobile-friendly design
- 🔐 User authentication
- 🗄️ Supabase database integration
- ⚡ Fast and interactive experience

## 🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- Supabase
- Vite

## 🚀 Live Demo

[View Live Website](https://cloud-kitchen-web-ap-lojq.bolt.host)

## 📌 Project Overview

This project demonstrates the development of a modern cloud kitchen web application with a responsive frontend, interactive components, authentication, and database integration.
